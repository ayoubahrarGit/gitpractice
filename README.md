## What LLM Code Looks Like

`llm_example.py` contains a self-contained, educational example of the core
building blocks found inside every Large Language Model (LLM):

| Concept | Description |
|---------|-------------|
| **Tokenization** | Converting text into numeric token IDs |
| **Embeddings** | Representing tokens as dense vectors |
| **Self-Attention** | Letting each token attend to every other token |
| **Transformer Block** | The repeating unit that stacks to form an LLM |
| **Text Generation** | Predicting the next token from model outputs |

### Run the example

```bash
python llm_example.py
```

The script uses only the Python standard library — no external dependencies are
required.
